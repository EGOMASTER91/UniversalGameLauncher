# GameHub Launcher

A premium, production-ready desktop UI/UX mockup for a unified gaming platform — combining design cues from Steam, Playnite, Xbox App, Discord, and modern AAA gaming dashboards.

## Features

- **Ultra-modern dark theme** with deep black + gray backgrounds and purple/blue accent lighting
- **Glassmorphism panels** with backdrop blur and ambient glows
- **Left sidebar** — Home, Library, Installed, Favorites, Recent, Downloads, Save Backups, Achievements, Mods, Settings
- **Launcher integrations** — Steam, Epic Games, GOG Galaxy, Ubisoft Connect, EA App, Battle.net, Xbox App, Riot Client
- **Hero banner** — animated featured game with Play / Continue, playtime, save-backup status, last-played info
- **Recently Played carousel** with progress bars, launcher pills, favorite stars, hover play button
- **All Games grid** with launcher badges and install status
- **Right sidebar dashboard** — Activity feed, Statistics, Weekly playtime chart, Save Backup ring, Storage panel with cloud sync
- Subtle animations, ambient glow tracking, and interactive controls

## Run

Open `index.html` in any modern browser. No build step required.

```bash
# Optional: serve locally
python3 -m http.server 8000
# then open http://localhost:8000
```

## Files

- `index.html` — markup & content
- `styles.css` — full design system
- `script.js` — interactive behavior (nav, filters, favorites, search shortcut, hero ambient tracking)
